# Markdown notes

[Home](index.html)

Markdown is a plain text format. GitHub turns it into formatted pages.

## Syntax I learned

| You write | You get |
| --- | --- |
| `# Title` | a heading |
| `**bold**` | **bold** |
| `*italic*` | *italic* |
| `[text](url)` | a link |
| `- item` | a bullet list |
| `1. item` | a numbered list |

## A code block

Use three backticks and a language name:

````
```c
#include <stdio.h>

int main(void)
{
	puts("Hello, World!");
	return 0;
}
```
````
